# v2.3.0 · Windows 桌面支持

## 新增平台

增加 Windows 10/11 x64 官网桌面 EXE 版支持，与 macOS 共用主题、CDP 注入和状态逻辑。新增平台适配层、Windows 安装入口、用户目录运行时、桌面快捷方式和三类发布包。

Windows 桌面入口使用 `.lnk → WScript/VBS → PowerShell → 专用 Node.js`，避免终端黑框。命名 Mutex 防止重复启动，成功后按 PID 恢复窗口并尝试置前；Windows 仍可能拒绝焦点切换，日志据实记录结果。Agent 不应在当前宿主会话执行强制重启。

## 稳定性修复

- 日志写入有有限重试；日志锁定、只读或路径不可写时不会阻断换肤、跳过窗口恢复或篡改子进程退出码。重试预算耗尽后，本次调用停止写日志，避免逐行反复等待。
- Windows PowerShell 命令采用 UTF-16LE `-EncodedCommand` 传入、UTF-8 输出，保护非中文系统上的中文快捷方式和路径；不要求用户改变系统区域设置。
- Git 属性固定源码与 CSS 为 LF，避免 Windows 自动 CRLF 转换破坏摘要校验；不修改历史 CSS 摘要来掩盖问题。
- 保留进程归属检查、安装失败保护和个人主题；Windows 无窗口 watch 的退出等待不影响宿主应用正常退出策略。
- 自动测试在独立临时目录覆盖日志占用、失败退出码、窗口恢复调用、快捷方式及升级保护。macOS/Windows × Node.js 22/24 为合并与发布检查矩阵。

## 下载文件

- `DoubaoWorkSkin-2.3.0-windows-scripts.zip`：Windows x64 安装包。

- 三个同名 `.zip.sha256` 文件：对应下载包的校验和。

## 更新方式

下载对应平台的完整包。macOS 运行 `安装皮肤.command`，Windows 运行 `安装皮肤.cmd`；安装保留已有个人主题、背景、配色和偏好。更新后重新应用原主题并执行验证。需要重启时先保存工作、等待当前 Agent 任务结束，再由用户打开平台启动入口；GitHub 发布不会自动升级本机安装。

## 支持边界与验收

Windows 支持目标限定为 Windows 10/11 x64 官网桌面版；当前已有 Windows 本机安装、注入与皮肤验证记录。Microsoft Store 版的代码分支仍属实验性且未完成真机验收；Windows ARM64 不支持；完全干净 Windows 的首次在线下载仍需独立验收。macOS 自动化 CI 不能替代 Apple 芯片/Intel 的真机完整流程。

发布前必须确认当前提交的四项 CI、主题资源检查、三类发布包的 SHA-256/CRC/清单/源码一致性/Unix 文件类型与权限校验通过，并在 macOS 用 `ditto` 实际解压确认两个 `.command` 仍可执行。日志竞争测试不接触真实豆包工作；源码测试通过不代表所有窗口焦点策略下都已真机验收。历史 `v2.2.5` 发布说明保留原样。
